# 🚗 **Car Demo**

## 📖 **Description**

This project is a **Java-based Car Simulation** developed to demonstrate the fundamental concepts of **Object-Oriented Programming (OOP)**. It models a real-world car by implementing different attributes and behaviors such as starting and stopping the engine, changing gears, controlling direction, monitoring fuel level, and displaying car information.

---

## ✨ **Features**

- 🚘 **Start and Stop Engine**
- ⚙️ **Automatic Speed Adjustment Based on Gear**
- 🔄 **Gear Management (1–5)**
- ⛽ **Low Fuel Warning**
- 🧭 **Direction Control**
  - Forward
  - Backward
  - Left
  - Right
- 📋 **Display Complete Car Details**
- 🏗️ **Default and Parameterized Constructors**
